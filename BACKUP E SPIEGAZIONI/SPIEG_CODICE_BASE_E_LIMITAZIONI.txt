FUNZIONALITÀ COMPLETE in start_watcher.bat:
- Cambio directory automatico: cd /d "%~dp0"
- Attivazione venv: call venv\Scripts\activate.bat
- Chiusura processi Office: evita file bloccati
- Pulizia SUBST precedente: python subst_manager.py remove
- Configurazione SUBST: python subst_manager.py setup
- Verifica configurazione: python subst_manager.py list
- Avvio watcher: python sync_watcher.py

LIMITAZIONE IDENTIFICATA
File Office (.docx, .xlsx, .pptx) hanno problemi con Google Drive perché Google Drive elimina automaticamente file che considera "corrotti" e i metadati Office non sono sempre compatibili dunque i file lock temporanei creano conflitti.

Usare OneDrive come repository principale per file Office sincronizza solo file finali (non durante la modifica) altrimenti convertire in .pdf per condivisione su Google Drive. Per altri file come documenti di testo, immagini, .pdf, codice, configurazioni e backup generali funziona perfettamente.
